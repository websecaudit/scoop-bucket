# WebSecAudit Scoop Bucket (Windows)

Install `web-vuln-scanner` on Windows using [Scoop](https://scoop.sh):

```powershell
scoop bucket add websecaudit https://github.com/websecaudit/scoop-bucket
scoop install web-vuln-scanner
```

Main repository: https://github.com/websecaudit/website-vulnerability-scanner  
Documentation: https://websecaudit.github.io/website-vulnerability-scanner/
